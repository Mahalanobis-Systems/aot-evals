# Refund and returns policy (the store's help center)

- **Refunds.** A delivered order can be refunded within 30 days of delivery; the 30th day counts.
  A refund is for the whole order, or for the items the customer names, and goes back to the
  original payment unless the customer asks for a gift card. An order is never refunded twice.
- **Returns.** A delivered order can be returned within 30 days of delivery. One return per order.
- **Address changes.** Only before the order ships.
- **Order status.** Customers can ask where an order is at any time.
- **Order numbers.** Every request about an order needs its number (A followed by four digits).
  When a customer doesn't give one, ask for it.
