# Help center topics

The topics customers can ask the support agent about, as the help center lists them. The
coverage lists (`coverage.yaml` in each eval) are taken from this page and from the refund
policy, not from the cases.

1. Track an order (order status, arrival date)
2. Start a return
3. Change a delivery address
4. Get a refund: a whole order, some items, or to a gift card
5. When we can't help: an unknown order number, a request past the 30-day window, an order that
   hasn't shipped or hasn't arrived, a request with no order number
