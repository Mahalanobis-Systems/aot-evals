How the simulation works

for each of 2,000 simulated teams, and each n in 20, 100, 500, 1,000, 2,000, 5,000, 10,000:
  gain = 0
  for change in 1..20:
    true_change ~ Normal(mean = +1 point, sd = 1 point)    # same draws for every test-case size

    # run the agent before and after the change on the same n test cases
    fix_rate   = 1% + true_change   # cases the change fixes   (if true_change < -1%: 0)
    break_rate = 1%                 # cases the change breaks  (if true_change < -1%: -true_change)
    fixes  ~ Binomial(n, fix_rate)
    breaks ~ Binomial(n, break_rate)

    observed = (fixes - breaks) / n
    flips    = (fixes + breaks) / n
    lower    = observed - 1.96 * sqrt((flips - observed^2) / n)   # 95% paired interval

    if lower > 0:            # the eval says it's a real improvement
      gain += true_change    # keep it: quality moves by its TRUE effect
    # otherwise: discard the change, quality stays where it is

report, for each n: the average gain after 20 changes, the middle two-thirds of teams,
how many changes were kept (and how many of those were harmful), and how many good ones were held back
