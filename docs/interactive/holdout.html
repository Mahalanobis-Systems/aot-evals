How the simulation works

for each of 2,000 simulated loops, and each n in 20, 100, 500, 1,000, 2,000, 5,000, 10,000:
  test_gain = 0; holdout_gain = 0
  for change in 1..K:                                         # K = changes tried, up to 30
    true_change ~ Normal(mean = +1 point, sd = 1 point)       # same draws for every n

    # measure it on the test set: before and after on the same n test cases (as in problem 11)
    fixes  ~ Binomial(n, 1% + true_change)                    # (if true_change < -1%: 0)
    breaks ~ Binomial(n, 1%)                                  # (if true_change < -1%: -true_change)
    observed = (fixes - breaks) / n
    flips    = (fixes + breaks) / n
    lower    = observed - 1.96 * sqrt((flips - observed^2) / n)

    if lower > 0:                       # the test set calls it a real improvement: keep it
      test_gain    += observed          # what the test set reports
      holdout_gain += true_change       # what a fresh holdout set reports, on average

report, for each n and K: the average test_gain and holdout_gain, and the gap between them
